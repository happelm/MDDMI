# Labfiles

| File | Lab | Purpose |
|---|---|---|
| `CmtraceInstall.ps1`, `CmtraceRemove.ps1` | 3.2 | Install and uninstall script for the Win32 app `CMTrace`: copies `CMTrace.exe` to `C:\Windows` and makes it the default viewer for .log files (script by Jorgen, CCMexec.com). The course share has them packaged with `CMTrace.exe` as `cmtrace.intunewin`. |
| `New-AndroidFMLevel1.ps1` | 4.6 | Creates Microsoft's Android Enterprise fully managed level 1 example (compliance policy and device restrictions) with Microsoft Graph, names `AE COBO ZT Level 1 …`; assigns them only with `-Assignment` |

`cmtrace.exe` and the other lab files (for example the Company Portal logo `ETCLogoTransparent.png`) come from the course share the trainer links in class; copy them to `C:\Scripts` on your vLab host. Later they will be offered as a ZIP from this repository.
