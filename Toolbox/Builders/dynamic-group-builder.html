Dynamic group rule builder

Draft: This tool is new and has not been tested in class yet.

Click together the membership rule for a dynamic device group in Microsoft Entra ID. The Entra rule builder only works for user groups – device rules go into the text box. This page writes that text for you, checks the syntax rules from Microsoft Learn and can build a PowerShell script that creates the group. The page signs in nowhere and sends nothing: everything stays in your browser.

3. Rule

      Entra admin center → Groups → All groups → New group: Group type Security, Membership type Dynamic Device → Add dynamic query → Edit next to the rule syntax → paste → OK. The Validate Rules tab tests the rule against devices you pick before you save.

      4. Optional: create the group with PowerShell

      The script creates a security group with dynamic membership (Graph POST /groups, permission Group.ReadWrite.All). Windows PowerShell 5.1 or PowerShell 7, module Microsoft.Graph.Authentication.

      Good to know
      • Filter or dynamic group? For Intune policies and apps, Microsoft recommends assignment filters when they meet the need: they evaluate at check-in and don't wait for group processing. Use dynamic device groups for Conditional Access, licensing, Autopilot profiles and other workloads outside Intune.
      • Dynamic groups aren't real time. A new device can take minutes to show up in the group.
      • deviceOwnership uses Company in Entra ID; Intune shows the same thing as Corporate. deviceTrustType: AzureAD = Entra joined, ServerAD = hybrid joined, Workplace = registered.
      • Device rules can only use device properties – no properties of the device owner. One group holds users or devices, never both.
      • Use -match and -contains sparingly – they slow down group processing. A whole rule can have up to 3,072 characters.
      • Dynamic device groups need no license for the devices. Dynamic user groups need Entra ID P1 for each member.

      Sources: Microsoft Learn – Rules for dynamic membership groups, Assignment filters.
