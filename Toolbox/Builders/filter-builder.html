Assignment filter builder

Draft: This tool is new and has not been tested in class yet.

Click together the rule for an Intune assignment filter. The page offers only the properties, operators and values Microsoft Learn lists for the platform you pick, and says in plain words which devices get the assignment. The page signs in nowhere and sends nothing: everything stays in your browser.

3. Rule

      Intune admin center → Tenant administration → Assignment filters → Create → Managed devices: name, platform → Rules → Edit next to the rule syntax → paste → OK. Preview devices shows enrolled devices that match before you save. In the policy: Assignments → Edit filter.

      Good to know
      • Include + match = gets it. Exclude + match = doesn't get it. A device that doesn't match an include filter doesn't get it.
      • If one device gets the same policy through several assignments: Exclude wins over No filter, and No filter wins over Include.
      • Filters are evaluated at enrollment and at every check-in – no group processing delay. But a property that is set after enrollment, like a device category chosen in Company Portal, is empty at the first check-in.
      • Use the filter on a user group, a device group or the All users / All devices virtual groups. For Conditional Access, licensing or Autopilot profiles you still need a dynamic group.
      • Up to 200 filters per tenant, up to 3,072 characters per filter. Managed app filters apply to app protection and app configuration policies only.
      • deviceOwnership is Corporate here; Entra dynamic groups use Company. deviceTrustType uses the Intune values like Azure AD joined, not the Entra values.
      • A filter on enrollmentProfileName breaks when you rename the profile – enrolled devices keep the old name.

      Sources: Microsoft Learn – Filter properties and operators, Assignment filters, Filter reports and troubleshooting.
